# EV Battery Health Prediction

A machine learning project for predicting the State of Health (SOH)
of electric vehicle batteries using battery operating and
degradation data.

## Problem Statement

Battery degradation directly affects the performance, range,
reliability, and safety of electric vehicles. This project aims
to develop a machine learning model that can estimate battery
State of Health from historical battery measurements.

## Objectives

- Analyze EV battery degradation data
- Preprocess battery cycle data
- Identify important degradation features
- Train multiple machine learning models
- Compare model performance
- Predict battery State of Health
- Build a simple interface for battery health prediction
